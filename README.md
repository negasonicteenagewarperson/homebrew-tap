# AK's Homebrew tap

Homebrew installs for apps I make.

## Cablehop

Move files between your Mac and your Android phone over USB or Wi-Fi. Browse your phone like a Finder
window, drag and drop, and nothing to install on the phone.
[Website](https://negasonicteenagewarperson.github.io/Cablehop/) ·
[GitHub](https://github.com/negasonicteenagewarperson/Cablehop)

```bash
brew install --cask negasonicteenagewarperson/tap/cablehop
```

Cablehop also updates itself (Cablehop › Check for Updates), or run `brew upgrade --cask cablehop`.

Cablehop isn't notarized by Apple yet, so the first time you open it macOS says it can't verify the app:
click **Done**, then **System Settings › Privacy & Security › Open Anyway**. You only do this once.
